# Project page credits

The page adapts the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template/tree/d38af1ccae1ce82c3404d2820c4c646afd409f81) and [Nerfies](https://nerfies.github.io/) under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). OptiPrime changes the layout, typography, replay and communication figure. Icons come from [Font Awesome Free](https://fontawesome.com/) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The sixteen-image replay uses small thumbnails of the sixteen evaluation inputs from [ImageNetV2, matched-frequency split](https://github.com/modestyachts/ImageNetV2). Each method's tiles follow its own measured completion times and carry its own secure prediction. Playback uses the same fivefold speedup on both sides.

The four-image replay uses [scikit-image sample photos](https://scikit-image.org/docs/stable/api/skimage.data.html): Chelsea by Stefan van der Walt, camera by Lav Varshney, coffee by Rachel Michetti, and rocket launch by SpaceX. [Four-image timing records](replay.json).
